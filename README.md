# Responsive Card Design

A set of three responsive cards built with HTML and CSS. Each card has an image, a title, a short description and a "Read More" button.

**Live Demo:** https://sabih-web.github.io/CSS-Cards/

## About the Project

I built this project to practise CSS card layouts, which are used in blogs, online stores and portfolio websites. The focus was on keeping the cards neat and making them adapt to different screen sizes, from desktop to mobile.

## What's Inside

- Three cards in a clean, aligned layout
- Image, heading, description text and "Read More" button on each card
- Responsive design that adjusts to the screen size

## Built With

- HTML
- CSS

## How to Run

1. Download or clone this repository
2. Open `index.html` in your browser

```bash
git clone https://github.com/sabih-web/CSS-Cards.git
```

## Note

This is a practice project made for learning purposes. The text on the cards is placeholder text.
